1.1 流量监控与分析

Quantumult提供实时流量监控功能，让用户清晰掌握数据使用情况。无论是日常浏览还是特定应用的数据消耗，都能通过直观的界面一览无余。

1.2 代理与分流管理

通过Quantumult，用户可以轻松配置多组代理服务器，并根据需求为不同网站或应用设置独立的代理规则。这种精细化的分流管理，让网络访问更加高效且个性化。

1.3 脚本支持与功能扩展

Quantumult支持用户自定义脚本，这意味着您可以根据特定需求扩展工具的功能。无论是广告屏蔽、自动签到，还是其他自动化操作，都能通过脚本实现。

二、安装与基础配置

2.1 安装步骤

  1. 获取应用：在App Store中搜索“Quantumult”并下载安装。
  2. 初次启动：打开应用后，您将看到简洁的主界面，此时需要添加代理配置以开始使用。

  • 获取节点信息：通常从订阅服务或手动配置中获取代理服务器的链接或参数。

2.3 启用代理

完成节点添加后，返回主界面，选择已配置的节点并启用代理模式。此时，您的网络流量将通过所选节点转发。

3.1 自定义分流规则

Quantumult的分流功能是其核心优势之一。您可以根据以下条件设置规则：
- 域名匹配：为特定域名（如google.com）指定代理或直连。
- 关键词过滤：通过URL中的关键词（如“netflix”）触发特定规则。
- 地域限制：针对特定地区的IP范围配置代理策略。

3.2 脚本的运用

通过编写或导入脚本，您可以实现以下功能：
- 广告屏蔽：自动过滤网页和应用的广告内容。
- 自动化任务：如定时切换节点、自动签到等。
- 流量优化：根据网络状况动态调整代理策略。

3.3 全局模式与智能分流

  • 全局模式：所有流量均通过代理转发，适合需要完全匿名或突破严格网络限制的场景。
  • 智能分流：根据规则自动选择代理或直连，平衡速度与隐私需求。

  • 切换节点：某些节点可能被目标网站封锁，尝试更换其他节点。
  • 更新配置：定期更新代理规则和节点列表，以适应网络环境的变化。

FAQ

Matsuri 节点排序功能如何提升访问效率？
Matsuri 会定期测速节点延迟，并结合策略组自动选择延迟低、稳定性高的节点处理不同流量。提升网页浏览、视频播放和游戏访问速度，减少掉线和卡顿。
SSR 的混淆和协议组合如何选择？
根据网络封锁情况选择适合的混淆和协议组合，例如 tls1.2_ticket_auth 模拟 HTTPS 流量。不同组合对抗 DPI 和封锁能力不同，需要测试后选择最稳定和高效的方案。
WinXray 支持测速功能吗？
支持。WinXray 提供节点延迟测速功能，可检测每个节点的响应时间与可用性。测速结果能帮助用户选择最快线路，也能排除无效或不稳定的节点，提高整体网络体验。
SSR 的协议参数和混淆参数如何配置最安全？
选择 AEAD 或协议插件可提升安全性，混淆方式如 tls1.2_ticket_auth 可以模拟正常 HTTPS 流量。合理搭配协议和混淆参数，能够有效抵御 DPI 检测和流量封锁。
VMess 使用 AEAD 加密对安全性有何帮助？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。高封锁环境下使用，有助于保持节点长期可用，保证数据安全和连接稳定性，同时降低被检测的风险。
Shadowrocket 的分流规则如何支持视频加速？
通过分流规则，将流媒体域名匹配到高速节点，其他网站走普通节点。这样可以保证视频播放流畅，同时节约带宽资源，提高整体网络效率和体验。
Hysteria2 的多路复用如何提高传输效率？
Hysteria2 利用 QUIC 的多路复用功能，将多个请求共享单个 UDP 连接，减少握手次数和延迟，提升整体吞吐量。尤其在高并发场景中效果显著。
Sing-box 如何精确匹配端口流量？
Sing-box 支持按端口设置流量分流规则，将不同类型流量分配到不同节点。结合策略组使用，可提高访问速度和稳定性，实现精准流量管理和优化网络体验。
Matsuri 节点排序如何提高视频播放流畅性？
Matsuri 会测速节点延迟，并结合策略组自动选择延迟低、稳定性高的节点处理视频流量。减少缓冲和卡顿，保证在线视频播放顺畅，提高整体网络体验。
Netch 的 Socks 模式有什么作用？
Netch 的 Socks 模式允许用户将代理仅应用于指定进程，而非全局网络。此模式非常适合单个游戏或程序代理，避免影响其他应用的连接方式与速度。
